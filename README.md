## Frontier NAT是什么意思？跟静态家宽有什么区别？

很多人搜"美国Frontier NAT VPS"的时候，其实还没完全搞清楚NAT的含义。这里顺手解释一下。

**NAT（网络地址转换）**的意思是：多台VPS共享同一个公网IP，通过端口映射的方式对外通信。你的VPS分配到的是内网IP，需要通过端口转发（port forwarding）才能被外部访问到特定服务。AaITR的NAT VPS提供**免费10个端口转发**，日常建站、代理、翻墙中转等基本够用。

**动态NAT**还有一个特点：IP每天0点自动刷新，也就是说每天醒来你的出口IP都是新的。对于不需要固定身份、主要用来翻墙或者低成本测试的场景，这是个优点；但对于需要稳定账号环境的业务来说，就是缺点了。

相比之下，**静态家宽**给你的是一个专属固定IP，独享不共享，IP不换，更适合对稳定性有要求的场景。
